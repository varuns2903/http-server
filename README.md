# High-Performance HTTP/1.1 Server

A production-quality, high-performance HTTP/1.1 web server built from scratch on Linux using modern C++20.

## Overview

This project is a learning and portfolio piece demonstrating deep knowledge of:
* C++20
* Linux/POSIX systems programming
* TCP/IP networking & Non-blocking I/O (epoll)
* Multithreading & Concurrency
* RAII and explicit resource management

## Project Roadmap

* **Sprint 0**: Project Foundation & Tooling (CMake, C++20, GoogleTest)
* **Sprint 1**: Blocking Echo Server (Raw TCP)
* **Sprint 2**: RAII Wrappers & Sockets
* **Sprint 3**: Non-blocking I/O & The Epoll Event Loop
* **Sprint 4**: HTTP/1.1 Parsing State Machine
* **Sprint 5**: Routing & HTTP Responses
* **Sprint 6**: Concurrency & Thread Pool Integration
* **Sprint 7**: Static File Serving & Optimization
* **Sprint 8**: Benchmarking, Profiling, & Stress Testing
